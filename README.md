# CampusLoop

A hackathon-ready Flutter MVP for a student-only campus marketplace/community.

## Tonight
1. Open this folder in VS Code.
2. Run `flutter pub get`
3. Run `flutter run`

No Firebase is required for this first MVP. The screens and demo flows work with local data.
